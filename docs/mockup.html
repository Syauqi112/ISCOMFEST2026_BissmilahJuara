Catatan buat Andre

  • Website, desktop dulu (demo di laptop), tetap responsif: di bawah ±900px kolom bertumpuk.
  • Pengguna utama orang tua: huruf badan ≥16px, tombol tinggi ≥44px, satu aksi utama per halaman, bahasa sehari-hari, angka dalam Rupiah.
  • Warna punya arti: kuning = listrik, biru = air, oranye bata = peringatan, biru tinta = brand/tombol. Jangan dicampur.
  • Kartu tanpa garis warna di kiri; pakai ikon alat dalam kotak lembut.
  • Setiap panggilan AI (cerita, audit, lonjakan): loading, error + coba lagi, empty state.
  • Semua angka dari backend. Frontend cuma menampilkan + menjumlah hemat misi yang dicentang. Panggil /api/... sesuai docs/API.md.
